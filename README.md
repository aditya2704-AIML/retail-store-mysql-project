# retail-store-mysql-project
Overview
This project analyzes retail store data using MySQL. The database includes customers, products, orders, payments, and reviews, and the project focuses on using SQL to explore business data and answer analytical questions. 
Retail-Store_MySQL_Project.sql


What I Did
Built and worked with a retail database in MySQL, then used SQL queries to analyze different parts of the business. The project covers filtering, aggregations, joins, subqueries, and set operations to examine customer activity, product performance, sales, and transactions.
